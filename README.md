# GhostBox skills

[GhostBox](https://ghostbox.me) gives each site its own email alias that forwards to your real inbox.

## Install

Copy the `ghostbox` folder into your agent's skills directory, or point your agent at this repo:

https://github.com/henny-ai/ghostbox-skills

```bash
cp -r ghostbox ~/.claude/skills/ghostbox
```

## MCP

Endpoint: https://api.decoy.henny.ai/mcp

Put your API key in the `DECOY_API_KEY` environment variable.
